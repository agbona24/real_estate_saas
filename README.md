# Real Estate SaaS Platform

A comprehensive multi-tenant Real Estate SaaS platform built with Laravel 11 and React.

## Features

- Multi-tenant architecture with agency management
- Complete CRM system (Leads → Prospects → Clients → Transactions)
- Property management (Land, Houses, Shortlet, Commercial, Estates)
- Client portal
- Website builder with themes
- Payment integration (Stripe & Paystack)
- Subscription billing
- Document management
- Multi-branch support
- Role-based access control (Super Admin, Agency Admin, Realtor, Client)

## Tech Stack

- **Backend**: Laravel 11, PHP 8.1+
- **Frontend**: React 18, Vite, Chakra UI, Tailwind CSS
- **Database**: MySQL 5.7/8.0
- **Payments**: Stripe, Paystack
- **Hosting**: cPanel compatible

## Installation

1. Upload files to your server
2. Navigate to `/install` in your browser
3. Follow the installation wizard
4. Complete database configuration
5. Set up admin account

## Requirements

- PHP >= 8.1
- MySQL >= 5.7
- Apache/Nginx
- Composer (for development)
